# Launch Antigravity

**Antigravity** is the DevPulse agent runtime. It connects external AI agents to your workspace through a real-time context bridge powered by RRO.

## What you get

- Live workspace context fed to your agents
- IPC bridge for sending and receiving structured messages
- Per-session sandboxing

Configure the endpoint with `devpulse.antigravity.endpoint` and run **Launch Antigravity Session** from the Command Palette.
