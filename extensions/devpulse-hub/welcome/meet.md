# Meet DevForge

DevForge is a custom build of VS Code from the **DevPulse** ecosystem, tuned for developers who want a distraction-free, high-signal editor.

## What's different

- **Deep Teal Tokyo Brutalist** theme tuned for long sessions
- Bundled DevPulse extensions for databases, AI overlays, and agent workflows
- Pre-wired status bar surface for the DevPulse platform
